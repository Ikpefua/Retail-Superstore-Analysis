# Retail-Superstore-Analysis
Excel Data Analysis and Dashboard Project

    OBJECTIVE
Analyse sales performance, profitability, customer behaviour,
regional trends, and discount impact using Excel.

   TOOLS USED
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Dashboard Design
- Data Analysis

     KEY INSIGHTS
• Technology generated the highest revenue.
• Office Supplies generated the highest profit.
• West region led overall performance.
• Discounts above 30% negatively impacted profitability.
• Some products generated high revenue but low profit.
